# Hospital AI Management System

A simple Hospital Management System developed using PHP, MySQL, HTML, CSS and JavaScript.

## Features

- User Login
- Patient Management
- Doctor Management
- Appointment Management
- AI Symptom Checker
- AI Medicine Recommendation
- MySQL Database

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Download this project from GitHub.
4. Extract the project into:

   C:\xampp\htdocs\

5. Open phpMyAdmin:

   http://localhost/phpmyadmin

6. Create a database named:

   hospital_ai

7. Import the `hospital_ai.sql` file.
8. Open the project in your browser:

   http://localhost/hospital_ai/

## Project Purpose

This project is developed as an academic MCA minor project to demonstrate hospital management and basic AI-based healthcare assistance.
